# Endless Backrooms
Thank you for visiting the repository! If you'd like to contribute to the mod, open an *issue* or submit a *pull request*. Any help is welcome.

***

Endless Backrooms is a mod that expands Minecraft with the dimensions, entities, and mechanics of the Backrooms.

Using a system of levels and liminal spaces, you'll be able to explore an unimaginable number of levels: from the classic yellow floors to hostile zones teeming with entities. Whether you're looking for psychological horror or just want to wander through empty, strange spaces, this mod is for you.

***

This mod is designed so that other modders can create add-ons that depend on it. Its MIT license allows you to use, modify, and distribute it freely.
